# React Test App

## 📌 Описание

Тестовое задание: реализация 3 страниц с использованием **React**. 
Вся логика управления состоянием реализована через **Redux Toolkit**. Данные о товарах получаются с внешнего API.

## 📄 Страницы

1. **Товары (`/catalog`)**  
   - Загружаются с внешнего API: [https://maxifoxy-testfront-4596.twc1.net/](https://maxifoxy-testfront-4596.twc1.net/)
   - Кнопки:
     - «В корзину» (при добавлении товара кнопка «В корзине» которая линкует в корзину)
     - «В избранное» (при нажатии добавляет товар в избранное, при повторном убирает из избранного)
     - «Отсутствует» (если `quantity === 0` и товара нет, в корзину нельзя добавить)
   - Если нет изображения — отображается заглушка.

2. **Избранное (`/favorites`)**
   - Отображает список добавленных в избранное товаров.
   - Возможность удалить товар из избранного.
   - Сообщение, если список пуст.

3. **Корзина (`/cart`)**
   - Отображает товары из корзины.
   - Кнопки: удалить, избранное, увеличить/уменьшить количество.
   - Подсчет суммы заказа.
   - Сообщение, если корзина пуста.
  
4. **Страница товара (`/product/id`)**
   - Отображает выбранный товар.

## 🛠️ Технологии

- **React**
- **Redux Toolkit**
- **React Router DOM**
- **SCSS (SASS)**
- **HTML5 семантическая верстка**

## 🚀 Запуск проекта

- клонируем репозиторий
- переходим на ветку dev
- npm i 
- npm run dev
- запускаем сайт http://localhost:5173/catalog
